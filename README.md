# MyToolWorld 项目文档

> 个人插件化工作台 — 本地运行、插件扩展、团队分享  
> 版本 v1.0 | 2026-08-08 交付

---

## 一、项目概览

### 1.1 这是什么

MyToolWorld 是一个基于 Electron + Vue 3 的桌面端插件化工具工作台。它本身不提供业务功能，而是一个**插件运行容器**：所有工具以插件形式按需安装、独立运行，侧边栏统一切换。

### 1.2 核心特点

- **插件化** — 工具箱只是一个壳，工具都是插件，按需安装/卸载
- **纯本地** — 所有数据存本地（localStorage / 用户数据目录），无需网络
- **可分发** — 插件打包成 zip 文件分享给同事，一键导入即可使用
- **主题可换** — 10 种主题色（商务蓝/暖棕/墨绿等），即点即换
- **插件隔离** — 外部插件在沙箱 iframe 中运行，崩溃不影响主程序

### 1.3 技术栈

| 层级 | 技术 |
|------|------|
| 桌面框架 | Electron 28 |
| 前端 | Vue 3 + Composition API |
| 构建 | Vite |
| 状态管理 | Pinia |
| 路由 | Vue Router（Hash 模式） |
| 打包 | electron-builder（NSIS + 绿色版） |
| 外部插件协议 | `plugin://` 自定义 scheme |

## 二、安装与运行

### 2.1 使用打包版本（推荐）

直接运行以下任一文件：
- **安装版**：`MyToolWorld Setup 1.0.0.exe`（~73 MB，支持自定义安装路径）
- **绿色版**：`MyToolWorld 1.0.0.exe`（~73 MB，免安装直接运行）

系统要求：Windows 10+，x64 架构。

### 2.2 开发环境运行

```bash
# 1. 安装依赖（国内网络环境）
$env:NODE_ENV = 'development'
npm install

# 2. 启动开发服务器（Vite + Electron 并行）
npm run dev

# 3. 仅启动前端（浏览器预览，外部插件导入不可用）
npm run dev:web
```

### 2.3 构建安装包

```bash
npm run build:electron
```

产物输出到 `release/` 目录（NSIS 安装包 + 绿色版便携包）。

> ⚠ 注意：如果 workspace 在同步盘上（如华为家庭存储），打包时 rename 操作可能失败，需将 `package.json` 中 `build.directories.output` 改为非同步盘路径（如 `C:/MyToolWorld-release`），构建完后拷回。

### 3.2 页面功能

#### 首页
- **常用插件**：按打开次数自动排序，展示 Top 6 插件卡片
- **最近使用**：按打开时间倒序，展示最近 5 个插件及其相对时间
- 点击卡片或列表项直接跳转到对应插件

#### 插件页面
- 侧边栏按分类分组展示所有已启用插件
- 点击分组头可折叠/展开
- 当前打开的插件高亮显示（左侧蓝色竖线）
- 底部「插件管理」入口（带已安装数量徽标）

#### 全局搜索（顶部搜索框）
- 输入关键词实时匹配插件名称、描述、分类
- 匹配结果高亮显示，点击跳转
- 快捷键 **Ctrl+K** 聚焦搜索框，**Esc** 关闭

#### 插件管理
- 表格展示所有插件：名称、版本、分类、来源（内置/外部）、描述、状态
- **启用/禁用**：禁用后侧边栏不显示，不影响数据
- **卸载**：二次确认弹窗，内置插件回归初始状态，外部插件删除目录
- **导入**：选择 `.zip` 插件包，自动校验并安装
- **导出**：外部插件可打包成 `.zip` 分享
- **拖拽排序**：拖拽表格行调整侧边栏显示顺序

#### 设置
- **主题色**：点击颜色点展开 10 色选择器，即选即生效（仅作用于框架元素，不影响插件内部）
- **版本信息**：显示当前版本号和技术栈
- **检查更新**：手动触发更新检测（需配置更新服务器）
- **插件管理入口**：显示已安装/已启用统计

### 3.3 内置插件

#### 个人任务管理
- 新建任务：标题、备注、截止日期、优先级（高/中/低）
- 三态切换：点击左侧方框循环「待办 → 进行中 → 已完成」
- 顶部筛选栏：全部/待办/进行中/已完成（带数量徽标）
- 排序：按创建时间/优先级/截止日期
- 过期任务红色标记，完成项划线
- 数据本地持久化

#### 大小写计算器
- 四则运算 + 括号
- 点击「大写」键：将计算结果或当前输入转为中文财务大写（壹贰叁…元角分整）
- 大写转换算法已全面测试（含"壹亿零壹"等复杂补零场景）
- 计算历史（最近 30 条）：点击回填，可清空

#### 抖音课程管理
- 添加课程：粘贴抖音链接 + 名称 + 备注 + 选择文件夹
- 文件夹管理：新建文件夹、按文件夹筛选
- 点缩略图新窗口打开视频
- 已学/未学状态：点击文字一键切换
- 数据本地持久化

### 关键文件职责

| 文件 | 职责 |
|------|------|
| `electron/pluginManager.js` | 插件注册表（读/写 `plugins-registry.json`）、导入校验（zip 解包→plugin.json 验证→安装→回滚）、导出打包、启用禁用、排序 |
| `electron/main.js` | 窗口创建、`plugin://` 协议注册（特权 scheme 声明 + 文件服务 + 路径穿越防护）、IPC 中转 |
| `src/stores/app.js` | 插件列表状态（Electron 环境通过 IPC 加载真实注册表，Web 预览降级到内置模拟）、使用统计（打开次数/最近时间持久化到 localStorage）、主题色切换 |
| `src/views/PluginView.vue` | 根据插件类型选择渲染方式：内置（`componentMap[plugin.id]` 直接渲染 Vue 组件）、外部（`<iframe src="plugin://...">` 沙箱加载） |
| `src/plugins/storage.js` | 各插件独立的 localStorage 持久化（命名空间 `MyToolWorld:{插件ID}:{键}`） |

## 五、数据存储

| 存储内容 | 位置 | 格式 |
|----------|------|------|
| 工作台配置（主题色） | `localStorage` → `MyToolWorld:workbench:accent` | JSON |
| 插件使用统计 | `localStorage` → `MyToolWorld:workbench:usage` | JSON |
| 插件业务数据（任务/历史/课程） | `localStorage` → `MyToolWorld:{插件ID}:{键}` | JSON（各插件独立） |
| 插件注册表（启用状态/排序/外部插件元数据） | `%APPDATA%/MyToolWorld/plugins-registry.json` | JSON |
| 外部插件文件 | `%APPDATA%/mytoolworld/plugins/<插件ID>/` | 原始文件 |

> ⚠ **注意**：外部插件存放在用户数据目录（`%APPDATA%\mytoolworld\plugins\`），而非安装目录（`Program Files\MyToolWorld`）。这是 Electron 的标准做法 — 用户数据与程序分离，卸载/覆盖安装不会丢失已导入的插件。你可以在文件资源管理器地址栏输入 `%APPDATA%\mytoolworld\plugins\` 直接访问。

> 卸载外部插件时同步删除对应目录和全部数据，不可恢复。

## 九、已知限制与后续规划

### 当前版本 (v1.0)

- 外部插件的 `window.workbench` API 目前为基础骨架（版本号/主题色/文件路径），完整文件读写需后续补齐
- 自动更新依赖 electron-updater，需配置更新服务器
- 仅支持 Windows x64

### 规划方向

1. 在线插件市场：浏览、一键安装
2. 多标签页：同时打开多个工具并行使用
3. 深色模式切换
4. macOS / Linux 跨平台适配
5. 插件安全审计与权限管控
